# Electrohold Power Market Analyst

## Overview
This repository contains the solution for the Power Market Analyst recruitment assignment.

- **Task 1:** Automated download of IBEX/ENTSO-E Day-Ahead prices, validation, market time-series analysis, and profile visualization.
- **Task 2:** Dynamic Excel-based price scale transformation without VBA/macros.

## How to Run Task 1
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   
2. Set ENTSO-E API Key (optional):
export ENTSO_API_KEY="ce4d798d-e828-425e-9529-1570fb8aad77"

3. Execute the analysis script:
python main.py
